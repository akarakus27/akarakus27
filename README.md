## 👋 About Me

I'm a **Cloud Data Engineer** and **Software Engineering graduate from Fırat University**.

I focus on designing and building **scalable, observable and cost-efficient data platforms**. My work spans the full data lifecycle — from ingestion and transformation to orchestration, analytics and AI-ready data layers.

- ☁️ **Cloud:** Google Cloud Platform, AWS
- 🏗️ **Data Platforms:** BigQuery, Dataform, Dataflow, Cloud Composer
- 🔄 **Pipelines:** Batch, streaming, ETL/ELT and CDC-oriented architectures
- 📊 **Analytics:** Data warehouses, medallion architecture, semantic layers
- 🤖 **AI + Data:** Gemini Enterprise, data agents and AI-ready analytics
- ⚙️ **Engineering:** Python, SQL, Spark, Kafka, Airflow, Docker, Kubernetes
- ✍️ **Writing:** Data Engineering, SQL, cloud architecture and engineering practices

> I enjoy simplifying complex data problems into reliable systems that are easier to operate, scale and understand.
